## 1. 安装

前往 [Releases](https://github.com/rangang/yunsuo/releases) 下载最新安装包。

### Windows 10/11（x64）

下载 `YunSuo_*_x64-setup.exe`，双击安装（简体中文安装界面）。系统一般已自带 WebView2 运行时；若缺失，安装器会自动引导下载。

### macOS 10.15+（Intel / Apple Silicon 通用）

下载 `YunSuo_*_universal.dmg`，打开后把「云梭」拖入「应用程序」。

应用未签名，首次打开会被系统拦截，任选一种方式放行：

- 在「应用程序」中**右键云梭 → 打开**，弹窗中再点「打开」；
- 或终端执行：`xattr -cr /Applications/云梭.app`

### 目标服务器要求

- Linux 服务器，以下两种接入方式任选其一：
  - **SSH**：可 SSH 登录即可；
  - **宝塔面板 API**：装有宝塔面板，无需开放 SSH。
- 前端项目部署需要服务器上有 `unzip`；健康检查需要 `curl`（绝大多数发行版自带）。

## 2. 添加服务器

进入左侧「服务器」页，点右上角「添加服务器」。顶部先选**连接类型**：SSH 或 宝塔面板。

### 方式 A：SSH

| 字段 | 说明 |
|------|------|
| 名称 | 随意，如「生产服务器」 |
| 主机 / 端口 | 服务器 IP 与 SSH 端口（默认 22） |
| 用户名 | 如 `root` |
| 认证方式 | 密码 或 私钥 |
| 密码 / 私钥路径 | 密码直接填写；私钥填本机私钥文件路径（如 `C:\Users\you\.ssh\id_rsa`），有口令则一并填写 |

密码 / 私钥口令存入系统凭据管理器（Windows 凭据管理器 / macOS 钥匙串），**数据库不落明文**。

### 方式 B：宝塔面板 API（无需 SSH）

先在**宝塔面板**上完成两步：

1. **开启 API 接口**：面板「设置 → API 接口」，打开开关，复制生成的 **API 密钥**。
2. **配置 IP 白名单**：把运行云梭这台电脑的**公网 IP** 加入白名单（不知道 IP 可先保存后点「测试连接」，面板的报错信息里会直接告诉你当前 IP）。

再回到云梭填写：

| 字段 | 说明 |
|------|------|
| 名称 | 随意，如「宝塔-生产」 |
| 面板地址 | **完整地址，含端口和安全入口**，如 `https://1.2.3.4:1178/xxxxxxxx`（浏览器登录面板用的那个地址） |
| 允许自签名证书 | 面板用自签 HTTPS 证书时勾选 |
| API 密钥 | 面板生成的密钥，同样只存系统凭据管理器 |

### 测试连接

保存后点卡片上的「测试连接」。成功会显示面板版本 / 系统信息（宝塔模式）或连接耗时（SSH 模式）。失败时按提示排查，常见原因见[常见问题](#8-常见问题)。

## 3. 新建项目

进入「项目」页，点「新建项目」：

| 字段 | 说明 |
|------|------|
| 项目路径 | 本地代码目录，如 `D:\projects\my-app`。选择后自动识别类型：有 `package.json` → 前端；有 `pom.xml` / `build.gradle` → Java |
| 项目名称 | 默认取文件夹名，可改 |
| 构建命令 | 前端默认 `npm run build`；Java 默认 Maven 打包（自动探测 PATH / MAVEN_HOME / IDEA 内置 Maven） |
| 产物路径 | 前端默认 `dist`；Java 如 `target/*.jar` |
| 构建前钩子（可选） | 构建前先执行的命令，如 `git pull` |

## 4. 部署配置

在项目详情页选择服务器和环境（支持多环境，如 default / staging / prod），点「部署配置」：

| 字段 | 说明 |
|------|------|
| 远程目录 | 部署根目录，如 `/www/wwwroot/myapp` 或 `/opt/order-service` |
| 站点文件夹名（前端） | 原子替换用的目录名，默认 `current`，一般不用改 |
| jar 文件名（Java） | 部署后的 jar 名，如 `app.jar` |
| 重启命令 | Java 必填（如 `systemctl restart myapp`）；前端可选。宝塔模式有默认值 |
| 健康检查 URL（可选） | 部署后用 `curl` 检查，HTTP 2xx/3xx 视为通过；失败会提示回滚 |
| 备份保留份数 | 保留最近 N 份旧版本供回滚 |
| 生产环境标记 | 开启后每次部署前弹窗二次确认，防止误操作线上服务 |

## 5. 一键部署

项目详情页点「部署」。流水线自动执行：

```
本地构建 → 产物打包 → 上传（SFTP 或宝塔 API）→ 远程备份 → 原子替换 → 重启 → 健康检查
```

- 构建与部署日志**实时流式输出**，上传显示进度和速度；
- 生产环境会先弹二次确认；
- 中途可点「取消」终止；
- 健康检查失败会提示回滚，服务器上的旧版本已自动备份，不会丢。

部署成功后桌面通知提醒（可在设置中关闭）。

---

## 6. 一键回滚

两个入口：

- 项目详情页「回滚」按钮；
- 「历史」页任意一条成功记录旁的回滚入口。

回滚会把最近一次备份原子替换回去并执行重启，同样有完整日志。可连续回滚到更早的备份（取决于保留份数）。

---

## 7. 历史与设置

- **历史页**：每次部署/回滚的完整记录、耗时、成功率统计；日志落盘，可导出。
- **设置页**：
  - 深 / 浅主题；
  - 开机自启动、托盘；
  - 部署成功 / 失败桌面通知开关，免打扰时段（时段内仅记录不弹通知）；
  - 日志敏感信息脱敏（密码等不出现在日志里）；
  - 部署默认值（重启命令、健康检查等的全局兜底）。

## 8. 常见问题

**Q：宝塔「测试连接」提示无法连接面板 / error sending request？**
面板地址必须带**端口**和**安全入口**，用浏览器能登录面板的那个完整地址。只填 IP 会连到 443 端口而失败。

**Q：宝塔提示证书错误？**
面板是自签 HTTPS 证书，编辑服务器勾选「允许自签名证书」。

**Q：宝塔提示 IP 不在白名单？**
报错信息里会带你的当前公网 IP，把它加进面板「设置 → API 接口」的 IP 白名单。注意家用宽带公网 IP 会变，变了要重新加。

**Q：宝塔部署提示「远程执行超时」？**
多为面板计划任务服务未运行。到面板「计划任务」页手动新建一个 Shell 任务（内容 `echo hello`）点「执行」再点「日志」，确认能看到输出；同时检查有无 `yunsuo-*` 残留任务，有则删除。

**Q：SSH 部署提示 unzip / curl 不存在？**
服务器上安装：`yum install -y unzip curl` 或 `apt install -y unzip curl`。

**Q：macOS 打不开应用，提示已损坏 / 无法验证开发者？**
未签名应用的正常拦截，见[安装](#1-安装)中的放行方法。

**Q：凭据存在哪里？安全吗？**
密码、私钥口令、宝塔 API 密钥全部存系统凭据管理器（Windows 凭据管理器 / macOS 钥匙串），应用数据库不落明文，日志默认脱敏。
